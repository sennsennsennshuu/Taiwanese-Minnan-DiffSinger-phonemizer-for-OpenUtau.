# DIFFS ZH-NAN-TW 台语音素器

本插件让 OpenUtau 的 DiffSinger 声库同时接受繁体台语用字、来源支持的简体/字形变体，以及无调或数字台罗。程序及文本使用 UTF-8；输入台罗不用带调号字母。DLL 按用户的 OpenUtau 0.1.572.3、.NET 10 真实程序集编译，不需要另装 Python 或 OpenCC 才能使用。

## 安装与选择

1. 将 `DiffSingerZhNanTw.dll` 放到 OpenUtau 的 `Plugins/` 目录，再重启 OpenUtau。
2. 为自己的台语声库选用本项目对应语言方案；将该方案的 `dsdict-zh-nan-tw-symbols.yaml` 复制到声库 `dsdur/`。这个精简字典只有音素分类和控制入口，能避免宿主加载数十万条重复汉字查询。没有精简字典时，插件兼容回退到完整 `dsdict-zh-nan-tw.yaml`，再回退到 `dsdict.yaml`。
3. 保留模型实际导出的 `dsconfig.yaml`、各模块 `phonemes.json` 和 `languages.json`。提供的训练方案片段不是完整模型配置，不能用来覆盖已训练模型的配置。
4. 在轨道选择 `DIFFS ZH-NAN-TW`。若要作为声库默认音素器，合并 `character-zh-nan-tw.patch.yaml` 中的 `default_phonemizer` 字段。

插件内嵌字词索引，无需再复制 100 MB 的来源追溯 JSON。音素映射优先使用实际模型支持的无前缀标签，其次使用 `zh-nan-tw/` 标签。

## 填写歌词

- 繁体与简体：`愛` / `爱`；连续两个音符填 `頭`、`路` 或 `头`、`路`，前端按词组识别并分别输出 `th au`、`l oo`。
- 台罗：`sann`、`tsit`、`tsit8`、`tai5-uan5`；数字只是输入读音标记，不是独立声调条件。
- 默认文白策略：主词目的白读优于其文读，因此 `我` 默认 `gua`，`夢` / `梦` 默认 `bang`；也可填 `夢@bong7` 明确选择文读。
- 同级异读：例如 `一`，可以填 `一@tsit8`、`一@it4`，或直接填 `tsit` / `it`。未指定时，索引按词频、来源支持数和稳定顺序选一个 `low` 置信度保底读音；`字词@1` 等候选序号也支持，但跨版本更推荐数字台罗明确读音。
- 普通话习惯词归一化：内嵌 `semantic-aliases.tsv` 包含 673 组映射，展开简繁字形后有 1,038 个入口。例如 `妻子→家後`、`工作→頭路`、`今天→今仔日`、`睡觉→睏`、`漂亮→媠`、`吃饭→食飯`、`喝水→啉水`、`孩子→囡仔`、`谢谢→多謝`、`没有→無`。命中的映射优先于同名原字读音；高置信度的完整原生固定词（例如 `大丈夫`）仍整体识别，避免替换其内部字串。
- 词义转换的手动覆盖：`工作@literal` 保留原字读法；`工作@kang1-tsok4` 或 `工作@1` 直接选原生候选，不经过语义层。`字词@literal` 也适用于整段汉字歌词。已有候选序号和台罗输入不变。
- 词组与句式：`phrase-aliases.tsv` 补充可组合的原生词块，并固定所需的文白读。例如 `天黑黑要落雨` / `天黑黑要下雨` 输出 `th inn oo oo b e -h l o -h h oo`，对应“天烏烏，欲落雨”；`要吃饭→欲食飯`、`要喝水→欲啉水`、`要睡觉→欲睏`、`要工作→欲做工`。规则支持整句和跨音符输入，并保留原歌词及字音边界。“要”只在列出的意愿或将要发生的词组中处理，“需要、重要、要求、必要、要緊”保留原生词义。所有目标词块必须是高置信度原生词条，选定的台罗音节必须逐项匹配当前字典；不把单字“要”全局改成“欲”。
- 音节数变化：`今天→今仔日` 按 `[2,1]` 将三个音节分配给两个输入字；`睡觉→睏` 虽然只有一个台语音节，分到两个音符时仍保留两组可显示音素：`睡[kh u]`、`觉[u -n]`。`我们→咱` 为 `我[l a]`、`们[a -n]`；`不会→袂` 为 `不[b e]`、`会[e]`。后组延续同一韵核，声母只在首组出现，韵尾只在最后一个延续组出现；不会删除后字组或写空发音结果。单个音符内的多个汉字仍使用该词原来的完整发音，不强行增添重复韵核。
- OpenUtau 的手动音素提示优先，例如 `一[ts i -t]`。多语模型可使用匹配的语言前缀，插件不会修改用户的提示。
- 鼻化与韵尾：`sann` 输出 `s ann`；`san` 输出 `s a -n`，二者不同。
- 原有延音 `+`、`+~`、`+*` 及宿主控制处理继续沿用。词组可以跨包含延音的相邻音符组，但不会跨休止、手动读音提示或其他语言的显式输入。

汉字歌词保持原文，转换仅发生在内部音符副本。用户手动提示和明确选音优先；未命中习惯词时沿用原生词典、文白读及低置信度保底。语义转换统一记录 `semantic-alias:` 来源和 `low` 置信度，表示词义未经过完整句法消歧；OpenUtau 界面不保证显示这个内部标记。

这些规则是离线词汇归一化，不能代替整句机器翻译。同一个普通话词仍采用确定性的默认义项，例如“我们”默认采用包括听者的 `咱`，排除听者请直接填 `阮`；“工作”默认名词 `頭路`，表示干活时可直接填 `做工`。姓名、地名和多义语境需要时使用 `@literal`、数字台罗或手动音素提示。

多语方案中，明确的 `zh/ni`、`ja/ka`、`en/hello` 等输入保留给宿主语言字典，裸汉字在本音素器中按台语处理。不会根据繁简字形猜测语言，也不声称自动处理中日英台混合自然文字。
